# HR Analytics Dashboard

## Project Overview
This project analyzes HR employee data using SQL and Power BI to identify workforce trends, employee attrition, salary insights, overtime impact, and job satisfaction patterns.

---

## Tools Used
- MySQL
- Power BI
- Excel

---

## Project Workflow
1. Data Cleaning
2. Data Validation
3. SQL Analysis
4. Advanced SQL Queries
5. Dashboard Development in Power BI

---

## Key Business Insights
- Research & Development had the highest attrition.
- Employees aged 26–35 showed the highest attrition.
- Overtime employees had higher attrition rates.
- Managers had the highest average salary.
- Job satisfaction varied across employees.
